# Job-Trend-Dashboard
This repository contains the Job Trend Dashboard project code.

This project creates a Job Trend Dashboard that shows how job trends change over time. It started from my own curiosity about how AI will impact the job market—especially how the number of job postings and the most in-demand roles will evolve. The dashboard will include trends in the number of jobs by job type and specific job titles, the current number of open positions, and emerging roles that have not appeared in the historical data. I hope this dashboard helps you understand how the job market has been changing and better anticipate future trends.
